# Code of Conduct

Mint Woodland Pet welcomes respectful, constructive participation.

## Expected behavior

- Be considerate and patient with people of different backgrounds and skill levels.
- Discuss ideas and code without personal attacks.
- Give actionable feedback and accept corrections gracefully.
- Respect privacy, copyright, licenses, and project boundaries.
- Keep reports relevant and avoid spam, harassment, or discriminatory language.

## Unacceptable behavior

Harassment, threats, sexualized attention, doxxing, deliberate disruption,
copyright abuse, and discrimination are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behavior violates these standards. Report ordinary
concerns through a GitHub issue. For sensitive safety or security matters, use
the private reporting path described in [SECURITY.md](SECURITY.md). Reports will
be reviewed as promptly and fairly as practical.

This code applies to repository issues, pull requests, reviews, discussions, and
other spaces where someone represents the project.
