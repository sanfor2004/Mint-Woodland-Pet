# Security policy

## Supported versions

Mint Woodland Pet is currently an early desktop prototype. Security fixes are
made on the latest `main` branch; older commits and unofficial builds are not
supported separately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form for this repository when it
is available. Include the affected commit, reproduction steps, impact, and any
suggested mitigation. Do not place exploit details, private data, or credentials
in a public issue.

If private reporting is unavailable, open a minimal public issue stating that
you need a private security contact, without including sensitive details. The
maintainer will arrange a private channel.

Please allow reasonable time to investigate before publishing vulnerability
details. You can expect an initial acknowledgement when the report is reviewed,
followed by status updates when there is material progress.
